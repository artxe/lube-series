# Language

Reply in the language the person writes in, even when the files, tool output and subagent reports around the reply are in English.

Every Markdown file in the repository (README, docs, `CLAUDE.md`, rules, skills) is in English. Korean appears in one only to quote what the code, the UI or the players use, or in a guide to the Korean text a game ships (its dialogue style).

In Markdown, replies included, a range is never written with `~` (two on one line strike out the text between them): use an en dash (`2–3`).
