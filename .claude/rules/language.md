# Language

The owner reads only Korean. Every message to the owner is in Korean, whatever language the prompt, files, tool output or subagent reports are in: the short briefings between tool calls as much as the final report. Each says in plain words what a thing is and what it changes for the owner before any options: no internal label (a part number, a commit hash, a skill or task name) and no jargon left unexplained.

What Claude reads is in English: `CLAUDE.md`, `.claude/` (rules, skills, `api/`), `TODO.md`, subagent briefs and their reports. Every other Markdown file is for the owner and is in Korean: README, docs, `TODO.decisions.md`, `TODO.checks.md`. A public repository, read by outsiders, has every Markdown file in English. No project's own file sets another language for them, and no third language is written for any reader. One appears only to quote what the code, the UI or the players use, or in a guide to the text a game ships in that language (its dialogue style).

In Markdown, replies included, a range is never written with `~` (two on one line strike out the text between them): use an en dash (`2–3`).
