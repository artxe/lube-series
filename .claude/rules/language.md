# Language

Every message to the person is in the language of their latest prompt (one that is only code, a command or pasted text keeps the language before it): the short briefings between tool calls as much as the final report, even when the files, tool output, subagent reports or earlier prompts around them are in another language.

Every Markdown file in the repository (README, docs, `CLAUDE.md`, rules, skills) is in English, unless the project's root `CLAUDE.md` names another language for them. Another language appears in one only to quote what the code, the UI or the players use, or in a guide to the text a game ships in that language (its dialogue style).

In Markdown, replies included, a range is never written with `~` (two on one line strike out the text between them): use an en dash (`2–3`).
